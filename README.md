# Mayorista Brasil

Plataforma de guia para revendedores paraguayos comprarem em Brás (São Paulo).

Stack: Next.js 14 + Firebase (Auth + Firestore + Storage).

Veja [SETUP.md](./SETUP.md) para instruções completas de instalação e deploy.

## Comandos

```bash
npm install        # Instalar dependências
npm run dev        # Rodar em desenvolvimento (http://localhost:3000)
npm run build      # Build de produção
npm run start      # Rodar build de produção
```
